StudyBuddy -Advanced Student Management System
Graduation Project | Human-Computer Interaction (HCI)
📖 Project Overview
StudyBuddy is an integrated academic platform designed to streamline the student experience. Our goal was to create a solution that addresses the complexity of managing courses, exams, and student support in one intuitive interface.

By applying HCI principles, we ensured that the platform is not just functional, but also reduces the mental effort required for students to navigate their academic life.

🧠 Core Features & Design Philosophy
Smart Student Dashboard: A centralized hub providing real-time visibility into academic progress and course updates.

User-Centered Interface: Built with a minimalist approach to eliminate distractions, focusing on "Visual Hierarchy" to guide the user's attention.

Inclusive Accessibility: Full support for both Dark and Light modes, allowing users to choose the environment that best fits their visual needs.

AI-Integrated Support: A dedicated AI Assistant module to provide instant guidance and help with academic inquiries.

Interactive Learning Tools: Features like synchronized course chats and interactive testing to improve student engagement.

🛠 Technical Framework
Frontend: Built with React.js and TypeScript for a robust and scalable architecture.

Design & Styling: Leveraged Tailwind CSS for a modern, responsive look across all screen sizes.

Deployment: Hosted via Vite and Vercel for optimized performance and speed.

🚀 Getting Started
Install project dependencies: npm install

Launch the development environment: npm run dev
